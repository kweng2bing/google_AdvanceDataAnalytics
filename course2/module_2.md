## EDA Process (Exploratory Data Analysis)
* A process of investigating, organizing, and analyzing data set.

1. Discovering: Familiarize themselves with the data for conceptualizing and usage
2. Structuring: Taking raw data and organizing or transforming it to more easily visualized
3. Cleaning: process of removing errors that may distort your data
    * Mispellings, duplicating, missing value
4. Joining: Process of augmenting or adjusting data by adding values from other data sets.
5. Validating: Process of checking for mispellins and inconsistent number or date formats
6. Presenting: Making cleaned data set or data visualization available to others for analysis
