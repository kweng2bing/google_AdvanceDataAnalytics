## Descriptive Statistics

### Definitions

**Measure of central tendency**: values that represent the center of a dataset

* Mean: average value in a dataset
* Median: middle value in a dataset
* Mode: most frequently occurring value in a dataset


**Measure of Dispersion**: describe the spread of your dataset, or the amount of variation in your data values

* Range: difference between the largest and smallest value in a dataset
* Variance: the average of the squared difference of each data point from the mean
* Standard Deviation: measures how spread out your values are from the mean of your dataset


**Measure of position**: Determine the position of a value in relation to other values in a dataset


* Percentiles: A value which represents a percentage of data falls. Percentiles divide your data into 100 equal parts. Percentiles give the relative position or rank of a particular value in a dataset
* Quartiles:  quartile divides the values in a dataset into four equal parts
